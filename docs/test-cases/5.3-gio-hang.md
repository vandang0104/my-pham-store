# 5.3 Kiểm thử chức năng giỏ hàng

**Phạm vi:** thêm vào giỏ, cập nhật số lượng, xoá dòng, trang giỏ hàng (tạm tính theo giá hiện hành), tự điều chỉnh giỏ khi sản phẩm đổi trạng thái/tồn kho, badge số lượng ở header, gộp giỏ khách vãng lai vào tài khoản khi đăng nhập / đăng ký.
**Công cụ:** Pest 4 (feature test qua HTTP nội bộ của Laravel), CSDL SQLite in-memory làm mới cho từng test (`RefreshDatabase`), dữ liệu tạo bằng factory.
**Mã nguồn test:** `tests/Feature/Cart/CartTest.php`
**Chạy:** `php artisan test tests/Feature/Cart`
**Kết quả lần chạy gần nhất:** 21/21 test case đạt (61 assertion). Các test case có nhiều bộ dữ liệu (dataset) được đếm theo từng bộ.

Quy ước dữ liệu: *Serum Niacinamide* giá 345.000 ₫ đang giảm còn **279.000 ₫**, tồn kho 5; *Kem dưỡng ẩm* 250.000 ₫, tồn kho 10. Khách vãng lai: giỏ lưu trong session; user đăng nhập: bảng `carts` / `cart_items`. Tài khoản đăng nhập mẫu `lan@example.com` / `MatKhau123`.
