# 5.1 Kiểm thử chức năng đăng ký, đăng nhập và phân quyền

**Phạm vi:** đăng ký, đăng nhập, đăng xuất, quên/đặt lại mật khẩu, phân quyền truy cập khu quản trị.
**Công cụ:** Pest 4 (feature test, chạy qua HTTP nội bộ của Laravel), CSDL SQLite in-memory làm mới cho từng test (`RefreshDatabase`), mail giả lập bằng `Notification::fake()`.
**Mã nguồn test:** `tests/Feature/Auth/` — RegisterTest, LoginTest, LogoutTest, PasswordResetTest, RoleAccessTest.
**Chạy:** `php artisan test tests/Feature/Auth`
**Kết quả lần chạy gần nhất:** 66/66 test case đạt (177 assertion). Các test case có nhiều bộ dữ liệu (dataset) được đếm theo từng bộ.

Quy ước dữ liệu: tài khoản mẫu `lan@example.com`, mật khẩu `MatKhau123` (trừ khi ghi khác). "Thông báo lỗi chung" = *"Email hoặc mật khẩu không đúng."*
