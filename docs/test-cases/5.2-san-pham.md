# 5.2 Kiểm thử chức năng sản phẩm: danh sách, tìm kiếm, lọc, chi tiết

**Phạm vi:** danh sách sản phẩm `/san-pham`, tìm kiếm theo từ khoá, lọc (danh mục, thương hiệu, khoảng giá, đang giảm giá), phân trang, trang danh mục `/danh-muc/{slug}`, trang thương hiệu `/thuong-hieu/{slug}`, chi tiết sản phẩm `/san-pham/{slug}`.
**Công cụ:** Pest 4 (feature test qua HTTP nội bộ của Laravel), CSDL SQLite in-memory làm mới cho từng test (`RefreshDatabase`), dữ liệu tạo bằng factory; `Model::preventLazyLoading()` bật khi chạy test (lazy load → lỗi).
**Mã nguồn test:** `tests/Feature/Products/` — ProductListTest, ProductShowTest.
**Chạy:** `php artisan test tests/Feature/Products`
**Kết quả lần chạy gần nhất:** 33/33 test case đạt (95 assertion). Các test case có nhiều bộ dữ liệu (dataset) được đếm theo từng bộ.

Quy ước dữ liệu (ProductListTest): danh mục **Chăm sóc da** (cha) → **Serum** (con), **Trang điểm**; thương hiệu **Dermalis Lab**, **Velvetine**. Sản phẩm: *Serum Vitamin C* (Serum, Dermalis Lab, SKU `DML-001`, giá 400.000 ₫ giảm còn 320.000 ₫), *Kem dưỡng ẩm* (Chăm sóc da, Velvetine, `VLV-001`, 250.000 ₫), *Son kem lì* (Trang điểm, Velvetine, `VLV-002`, 180.000 ₫).
